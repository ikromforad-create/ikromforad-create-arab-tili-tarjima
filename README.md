# Arab tili tarjima

Codex uchun arabcha → o‘zbekcha ilmiy, badiiy va klassik matn tarjimasi uchun professional skilllar to‘plami.

## Maqsad

Tarjima jarayonini uch bosqichga ajratish:

1. **Tahlil** — arabcha matnning nahv, sarf, lug‘at, balog‘at va kontekstini aniqlash.
2. **Tarjima** — matn janriga mos tabiiy va aniq o‘zbekcha tarjima yaratish.
3. **Tekshiruv** — original va tarjimani taqqoslab, ma’no yo‘qolishi, qo‘shilishi va terminologik xatolarni aniqlash.

## Skilllar

- `arabic-text-analysis` — arabcha filologik tahlil
- `scientific-arabic-translation` — ilmiy va akademik tarjima
- `literary-arabic-translation` — badiiy tarjima
- `islamic-classical-translation` — diniy va klassik matnlar
- `translation-review` — tarjima sifat nazorati
- `arabic-uzbek-terminology` — terminologiya izchilligi

## Asosiy prinsip

**Aniqlik → ma’no → uslub → tabiiy o‘zbek tili.**

So‘zma-so‘z tarjima faqat ma’noni saqlash uchun zarur bo‘lgan hollarda qo‘llanadi; ma’noni buzadigan literal tarjimadan foydalanilmaydi.
