# Arabic → Uzbek Terminology

## Purpose
Build and maintain a terminology map for the current work. Consistency matters more than forcing one universal translation for every context.

## Rules
1. Identify recurring Arabic technical terms before or during translation.
2. Prefer established Uzbek scholarly terminology when confidently known.
3. Keep one preferred equivalent for a term within the same work unless context clearly requires another.
4. Distinguish lexical and technical meanings.
5. Preserve Arabic in parentheses on first occurrence when the Uzbek equivalent could be ambiguous or the Arabic term is academically important.
6. Do not translate proper names as ordinary vocabulary.
7. Track singular/plural and related derived terminology consistently.
8. If no reliable Uzbek equivalent exists, use a careful transliteration or the Arabic term with a concise explanation outside the translation.
9. Never invent terminology merely to avoid retaining an Arabic term.

## Recommended map
Use a table internally:

| Arabic | Preferred Uzbek | Alternative | Domain | Note |
|---|---|---|---|---|

At the end of a long project, the terminology map can be saved as a project glossary and reused for later chapters.
